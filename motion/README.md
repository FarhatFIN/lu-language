# LuMotion — моушн-графика на Lu

Мини-редактор композиций в духе After Effects: слои, кейфреймы, превью
в реальном времени и headless-рендер в PPM. Всё написано на Lu и собирается
компилятором `luc` — ни строчки C в исходниках, кроме `Import`-заголовков
X11.

```
motion/
  core.lu       модель, кейфреймы, растеризатор, шрифт, формат .lum
  render.lu     headless-рендерер (PPM, без окна)
  motion.lu     X11-редактор
  examples/     пример проекта
  test.sh       детерминированные проверки
```

`core.lu` — библиотека: `render.lu` и `motion.lu` подключают её одной
строкой `incl <core.lu>`. Поэтому сцена, отрисованная в редакторе, и сцена,
отрендеренная из скрипта, — это буквально один и тот же код.

## Сборка

```bash
cd motion

# редактор
../src/luc motion.lu -o motion.c
cc -O2 -std=c11 motion.c -lm -lX11 -o lumotion

# рендерер
../src/luc render.lu -o render.c
cc -O2 -std=c11 render.c -lm -o lumotion-render
```

Нужны `libX11` (редактор) и больше ничего: ни SDL, ни OpenGL, ни шрифтовых
библиотек. Или одной командой:

```bash
./test.sh        # соберёт оба, прогонит проверки и уберёт временные файлы
```

Редактор написан на основном синтаксисе Lu (`Lu/Language`), а не на
`Lu/Strict`: v5 не умеет вставлять `X11/Xlib.h` и не принимает `;`, а
шаблон X11-приложения в этом репозитории — v4.

### Клавиши

| Клавиша | Действие |
|---|---|
| `Space` | play / pause |
| `←` `→` | кадр назад / вперёд |
| `Home` / `End` | первый / последний кадр |
| `↑` `↓` | выбрать слой |
| `1`…`5` | добавить слой: прямоугольник, эллипс, текст, градиент, свечение |
| `X` | удалить слой |
| `V` | видимость |
| `B` | режим наложения (NORMAL → ADD → MULTIPLY → SCREEN) |
| `E` | ease кейфрейма (LINEAR → SMOOTH → HOLD) |
| `C` | следующий цвет из палитры |
| `K` | поставить кейфрейм в текущем кадре |
| `Delete` / `Backspace` | удалить кейфрейм в текущем кадре |
| `T` | править текст слоя (`Enter` — применить, `Esc` — отмена) |
| `A` `D` `W` `S` | сдвинуть слой на 4 px |
| `-` `=` | масштаб −8 % / +8 % |
| `,` `.` | поворот −0.06 / +0.06 рад |
| `9` `0` | прозрачность −0.05 / +0.05 |
| `S` | сохранить в `out.lum` (или в файл, открытый при запуске) |
| `Esc` | выход |

Мышь: клик по превью выбирает слой под курсором, перетаскивание двигает его,
клик по строке в списке слоёв или по дорожке таймлайна выбирает слой,
колесо прокручивает списки.

**Auto-key.** Отдельного режима записи нет: любое изменение позы (стрелки,
масштаб, поворот, альфа, перетаскивание) сразу пишет кейфрейм в текущем
кадре. Первый кейфрейм слоя создаётся при его добавлении, так что слой
всегда имеет хотя бы одну позу.

## Рендерер

```bash
./lumotion-render --demo --info                  # что внутри сцены
./lumotion-render examples/title.lum --info
./lumotion-render examples/title.lum --still 42 frame.ppm
./lumotion-render examples/title.lum --seq frames 0 149
./lumotion-render --demo --write scene.lum       # демо-сцену в файл
```

`--still` пишет бинарный PPM (`P6`), `--seq` — `frame_0000.ppm` … в каталоге.
Кадры детерминированы: один и тот же проект и номер кадра дают байт-в-байт
одинаковый файл, поэтому выводимый ряд можно складывать в git и сравнивать
`cmp`. Номер кадра за пределами композиции зажимается в `0..dur-1`.

Собрать видео из последовательности:

```bash
ffmpeg -framerate 30 -i frames/frame_%04d.ppm -pix_fmt yuv420p out.mp4
```

## Формат `.lum`

Текстовый, по строке на запись; строки, начинающиеся с `#`, пропускаются,
как и незнакомые ключи. Цвета — `0xRRGGBB`.

```
lum 1
comp 640 360 30 150 657930 1448202 1        # w h fps dur bg0 bg1 gradient
name lu-motion-title
layer 3 0 1 657930 1778220                  # kind blend visible color color2
pos 320.000 180.000 320.000 180.000 0.000 1.000
text LUMOTION                               # только у текстовых слоёв
key 0.000 320.000 180.000 320.000 180.000 0.000 1.000 1
end
```

- `kind`: `0` RECT, `1` ELLIPSE, `2` TEXT, `3` GRADIENT, `4` GLOW.
- `blend`: `0` NORMAL, `1` ADD, `2` MULTIPLY, `3` SCREEN.
- `pos` — поза без кейфрейма (базовая), `key` — время в кадрах, поза
  (`x y sx sy rot alpha`) и `ease` (`0` LINEAR, `1` SMOOTH, `2` HOLD).
- Поза интерполируется между соседними кейфреймами; до первого и после
  последнего действует крайний.

## Как это нарисовано

Ни одной библиотеки растеризации: `core.lu` считает покрытие пикселя
аналитически. Для каждого пикселя берётся обратное аффинное преобразование
в локальные координаты слоя, вычисляется расстояние до границы фигуры `d`,
и цвет смешивается с покрытием `clamp(d * edge + 0.5)`. Отсюда ровные края
на любом повороте и масштабе, без суперсэмплинга.

- `RECT` — расстояние до прямоугольника, `ELLIPSE` — до эллипса
  (нормализованное), `GRADIENT` — линейный градиент `color → color2`
  с той же маской, `GLOW` — радиальный профиль `(1-r)²·(0.55+0.45(1-r))`.
- `TEXT` — встроенный шрифт 5×7: 52 глифа (`A–Z`, `0–9`, пунктуация),
  7 строк по 5 бит на глиф. Строчные буквы поднимаются в заглавные —
  шрифт намеренно без нижнего регистра.
- Наложение — по альфе с учётом blend-режима; композиция целиком
  перерисовывается в буфер `w*h*3` и оттуда копируется на экран.

Редактор держит один 32-битный фреймбуфер окна (`WIN_W × WIN_H`) и рисует
в него своими примитивами — рамки, линии, ромбы кейфреймов, текст тем же
шрифтом. На экран уходит один `XPutImage` за перерисовку, поэтому играть
150 кадров можно без мерцания и без X-таймеров: цикл событий сам считает
`dt` по монотонным часам.

## Пределы

| Что | Сколько |
|---|---|
| Слоёв в композиции | 32 |
| Кейфреймов на слой | 24 |
| Символов в тексте слоя | 96 |
| Символов в имени проекта | 127 |
| Палитра | 10 цветов |

Ограничения — размеры массивов внутри `struct Comp`/`struct Layer`; они
заданы литералами, потому что верхнеуровневые `const` в Lu эмитятся после
структур.

## Проверки

```bash
./test.sh
make -C ../src test-motion   # то же самое из каталога компилятора
```

Скрипт собирает оба бинарника через `luc`, проверяет состав демо-сцены,
заголовок и размер PPM, детерминированность кадра, зажим номера кадра,
диапазон `--seq`, round-trip `--write` → загрузка, загрузку
`examples/title.lum` и диагностику на отсутствующий файл и неизвестный
флаг.
